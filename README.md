# Rally Queue

A mobile-first badminton court queue and fair-play rating system. The current MVP runs immediately with persistent demo data and includes the Supabase schema required for production accounts, realtime updates, and row-level security.

## Quick start

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. No environment variables are required for demo mode.

See [PROJECT_SETUP.md](docs/PROJECT_SETUP.md) for Supabase, admin, testing, and deployment steps.

## Commands

- `npm run dev` starts the local app.
- `npm test` runs domain-rule tests.
- `npm run lint` checks source quality.
- `npm run build` creates the production bundle.
